Creator Guide

Practical workflow notes for building constructs, enemies, weapons, patterns, and levels.

Fast Start

1. Install examples Open the Suite and click Install Example and Install Zone Enemies.
2. Edit a construct Open Mob / Construct, choose a model in Load Construct, then paint, erase, or connect cells.
3. Build an enemy Open Enemies, choose a template, assign a construct and patterns, then tune movement and animation.
4. Export the pack Use Download JSON for one asset, or import/export full module folders through the Suite.

Construct Workshop

  • Load Construct lists bundled constructs, sculpted zone enemy examples, and constructs installed from browser-local packs.
  • Paint places or changes cells using the selected cell type. A construct should usually have one clear core.
  • Erase removes a cell and any connections attached to it.
  • Connect links two adjacent cells. Runtime connectivity follows explicit graph edges, so disconnected cells will not behave like attached structure.
  • Layer edits stacked gridZ cells. Lower layers can be ghosted while upper layers stay hidden.
  • Connect Above and Connect Below link the selected cell to the matching X/Y cell on the next vertical layer.
  • Gun loadout controls apply to the selected gun cell and let one construct carry multiple weapon choices.

Mesh Voxelizer

  • Import .obj or ASCII .stl mesh files and convert sampled mesh surfaces into ordinary construct JSON.
  • The first pass chooses one core near the mesh centroid, makes other occupied cells armor, and creates explicit adjacency connections.
  • Open the generated JSON in the Construct Workshop to assign cell types, gun loadouts, special roles, and cleaner hand-authored connections.

Enemy Editor

  • Canon Template loads a starting enemy descriptor, including the new zone enemy examples.
  • Construct chooses the body model. Known constructs draw in the preview; runtime-only ids remain valid text references.
  • Patterns are firing behaviors. Use the Weapon + Pattern Lab to tune projectile shape, timing, spread, arcs, and status effects.
  • Movement, Aggregate, and Cell Animation are editor descriptors for richer enemies such as walkers, phased enemies, carriers, and bosses.
  • Selectors such as type:armor, role:supportLeg, or all choose which cells an animation affects.

Local Modules

  • Imported packs are stored in the current browser under this site origin, so the local editor and GitHub Pages editor keep separate browser-local libraries.
  • A complete pack manifest should reference dependent JSON assets together. For example, an enemy archetype pack should include the construct and pattern files it needs.
  • The current game validates and stores local content now; some gameplay runners still need adapters before every editor-authored descriptor becomes live combat behavior.
